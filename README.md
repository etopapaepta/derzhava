# Держава на GitHub Pages

Игра с мультиплеером: главное меню → «Мультиплеер» → выбери страну → «Основать столицу» → «Пригласить друга» → отправь ссылку.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | игра |
| `rooms.js` | правила комнаты для игры вдвоём |
| `duel-map.json` | карта материка для игры вдвоём |
| `.nojekyll` | просит GitHub отдавать файлы как есть |

## Как опубликовать (через сайт GitHub, без программ)

1. Войди на github.com → справа сверху «+» → **New repository**.
2. Название, например `derzhava`, видимость **Public** → **Create repository**.
3. На странице нового репозитория нажми **uploading an existing file** и перетащи файлы из этой папки: `index.html`, `rooms.js`, `duel-map.json`, `.nojekyll`. Файл `.nojekyll` скрыт в Finder: нажми ⌘⇧. (Cmd+Shift+точка), чтобы его увидеть.
4. Внизу нажми **Commit changes**.
5. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты игра откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/derzhava/`.

## Как играть с другом

1. Открой игру → **Мультиплеер** → выбери страну → **Основать столицу**.
2. В игре нажми **Пригласить друга** → **Скопировать** → отправь ссылку другу.
3. Друг открывает ссылку, выбирает свою страну той же эпохи → **Войти на карту**.

Важно:
- Комната живёт в браузере того, кто её создал. Пока вы играете, его вкладка с игрой должна быть открыта. Закрыл — партия на паузе. Открой игру снова, нажми **Вернуться в комнату**, и друг снова сможет войти.
- Браузеры обмениваются сообщениями через бесплатные публичные MQTT-ретрансляторы (HiveMQ, запасной — EMQX) по защищённому WebSocket. Это работает через VPN, мобильный интернет и роутеры. Все сообщения зашифрованы ключом из ссылки-приглашения: ретранслятор видит только шифр. Ссылку отправляй только тому, с кем играешь.

## Как обновить игру

В папке проекта выполни `python3 tools/build_pages.py`, затем загрузи новый `index.html` в репозиторий так же, через **Add file → Upload files**.
